# Support

Use [GitHub issues](https://github.com/49-Agents/agent-dms/issues) for reproducible
bugs, setup questions and workflow proposals. Include agent-dms version, OS,
Python and client versions, transport, expected result and the smallest synthetic
reproduction. Remove tokens, identifying paths and private message bodies before
sharing logs or configuration.

Linux with Python 3.11/3.12 is the tested baseline. Official SDK HTTP/stdio
clients are verified. Native Claude Code/Codex acceptance is tracked separately
in [the client check](docs/NATIVE-CLIENT-ACCEPTANCE.md); provider labels alone
do not establish compatibility. Native Windows is unsupported. macOS, WSL,
newer Python and third-party MCP hosts need their own evidence.

Questions and patches receive best-effort maintainer attention. There is no
hosted service, paid support plan or availability guarantee. See
[SECURITY.md](SECURITY.md) for private vulnerability reporting.
