# agent-dms

A project-local MCP server for cross-provider agent discovery, current-work
status, and durable direct messages. A 49Agents product.

**Status: private development; implementation planned.** The initial design
connects existing Claude, Codex and other MCP clients to one project service.
Agents maintain a status of at most 30 words, discover peers, exchange persistent
DMs, and coordinate ACLA handoffs, questions and reviews.
